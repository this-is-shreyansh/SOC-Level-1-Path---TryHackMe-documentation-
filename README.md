# SOC Level 1 Practical Investigation Portfolio & Reference Guide

A structured repository tracking hands-on security operations training, simulated incident response case studies, and defensive tooling reference guides based on the **TryHackMe SOC Level 1** path.

---

## 🎯 Repository Purpose

* **Portfolio of Practical Incident Reports:** Document end-to-end alert investigations, network forensics, phishing triage, and SIEM hunts.
* **Defensive Tool Reference:** Maintain practical query cheat sheets and workflow guides for Splunk, Wireshark, Zeek, and Windows Event Logs.
* **Progress Tracker:** Act as a central roadmap and checklist across foundational SOC analysis domains.

> **Disclaimer:** In accordance with platform terms of service, this repository contains **no flag solutions, direct answer dumps, or proprietary lab material**. All reports focus strictly on investigative methodology, MITRE ATT&CK mapping, log analysis, and remediation steps.
